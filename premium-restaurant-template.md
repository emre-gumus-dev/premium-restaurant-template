# Premium Restaurant Template 🍽️

A high-performance, fully responsive restaurant website template built with pure HTML5, CSS3, and Vanilla JavaScript. Designed for international clients who value speed, aesthetics, and clean code.

![Restaurant Preview](https://images.unsplash.com/photo-1517248135467-4c7edcad34c4?w=1200&q=80)

## ✨ Features

-   **Zero Dependencies:** No frameworks, no bloat. Just pure, optimized code.
-   **Mobile-First Design:** Flawless experience on all devices.
-   **Custom Animations:** Particle effects, smooth scrolling, and scroll-reveal animations.
-   **SEO Optimized:** Semantic HTML structure and meta tags for better search ranking.
-   **Multi-Language Ready:** Easy to extend for TR/EN or other locales.
-   **Accessible:** WCAG compliant color contrast and ARIA labels.

## ️ Tech Stack

-   HTML5
-   CSS3 (Flexbox, Grid, Custom Properties)
-   Vanilla JavaScript (ES6+)
-   Git & GitHub
